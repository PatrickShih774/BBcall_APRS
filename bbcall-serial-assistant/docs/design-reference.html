01

设计定位

一句话：用工程仪表盘的语汇承载 PC 端外壳，用设备的 1-bit 点阵承载屏幕镜像。 外壳是暗色工具界面（tech-utility 语汇：Datadog / GitHub 一类的高信息密度控制台）， 设备屏则严格回到固件 docs/design.md §2 的 ink / paper 双色，两者不互相污染。

原则 01
数字优先

所有数值走等宽字体并开启 tabular-nums，纵向对齐；读数、时间戳、寄存器一律不参与比例字体排版。

原则 02
直角与硬边

圆角恒为 0，阴影是不模糊的位移影（2px 2px 0）。按下时按钮位移吃掉阴影——这是全站唯一的“动效语言”。

原则 03
单一强调色

accent 只表达“当前/可操作/发送中”。状态色 ok / warn / danger / info 只在标签与数值上着色，不用于大面积填充。

原则 04
点阵是唯一装饰

4px 栅格上的单像素点构成全站唯一的装饰母题。除此之外不引入纹理、渐变、插画或图标集。

03

排版系统

四个字体栈各司其职：界面用系统无衬线，数据用等宽，标题与眉标复用等宽字栈（--font-display 即 mono）， 设备屏单独一套（中文点阵感优先）。不引入任何网络字体，全部走系统栈以保证离线可用。

令牌字栈用途
--font-ui系统无衬线 / 微软雅黑 / 苹方正文、按钮、下拉、说明文字
--font-monoJetBrains Mono → 系统等宽数值、命令、日志、时间戳、标签
--font-display同 mono品牌字、面板标题、区块标题
--font-lcd微软雅黑 / 苹方 → 等宽128×64 屏幕镜像（中文点阵优先）

04

点阵母题

背景不是纯色，而是 4px 栅格上的 1px 圆点（radial-gradient 平铺）。 两种强度：--dottex 用于页面底，--dottex-soft 用于中栏与卡片底以便压低对比。 这是全站唯一的装饰笔触，不叠加其他纹理。

令牌值落点
--dotoklch(25% 0.014 250)页面底 · --dottex
--dot-softoklch(24% 0.013 250)中栏 / 卡片底 · --dottex-soft
background-size4px 4px与点阵栅格对齐，缩放时保持整数倍

布局栅格

三栏固定工作区。关键决定：余量按 1 : 1.6 : 1 比例分给三栏，而不是让中栏独占 1fr。 否则在 1920 宽下中栏会吃掉千余像素、日志行又短，视觉上就“空”。

07

屏幕镜像

镜像不是“画一张屏幕图”，而是把设备 128×64 的 1-bit 帧缓冲按整数倍放大复刻： 离屏渲染 128×64 → 关闭插值 → 整倍放大。因此镜像里只有两种颜色（ink / paper），换主题即换这一对令牌。

08

交互状态

规则：状态变化只改背景 / 边框 / 位置，绝不把前景色往背景方向推。 默认态与悬停态的文本对比度要求一致（正文 ≥ 4.5:1，大字与图标 ≥ 3:1）；只有禁用态允许降对比。

Default
Hover

底色 24%→29%，纹理（边框）提亮，前景不变。

Focus-visible

2px accent 焦点环，offset 2px，全站统一。

Active

位移吃掉阴影，位置 +2px/+2px。

Disabled

opacity .45，唯一允许降对比的状态。

Selected

chip 反相：底=fg，字=bg，对比反而升高。

对比度清单

配对用法目标
--fg / --bg · --surface正文、数值、按钮文字≥ 4.5:1
--muted / --bg次要文本、单位、说明≥ 4.5:1
accent / bg焦点环、选中下划线、链路点≥ 3:1（图形）
ok·warn·danger·info / surface-2标签文字（11px）≥ 4.5:1
实心主按钮：oklch(18% .03 150) / accent主按钮文字≥ 4.5:1，悬停时同时反转两者
09

结构与约定

项约定
载体单文件 HTML，内联 CSS/JS，零构建、零网络依赖；另存即可用
定位标注每个可被引用的区域 / 标题 / 控件带 data-od-id（kebab-case，重复卡片各自唯一）
持久化localStorage，键前缀 bbcall.*：串口、波特率、右栏标签页、日志过滤、镜像主题
滚动禁用 scrollIntoView（会破坏内嵌预览），改用容器自身的 scrollTop
颜色写法令牌在 :root 用 oklch()；页面上不出现裸 hex，派生色用 color-mix(in oklch, …)
动画只用 steps() 的像素式过渡与位移影，无缓动曲线、无模糊
无障碍:focus-visible 焦点环、aria-selected / aria-pressed 表达选中、prefers-reduced-motion 关闭动效
响应式920–980px 由三栏折为单栏，不横向滚动；不写死像素宽度
本页为本助手的视觉与组件参考，令牌取自同目录的 bbcall-serial-assistant.html；设备屏色值取自固件 docs/design.md §2。 操作说明见 user-guide.md，串口协议见 serial-protocol.md。
