# 操作手册 — BBcall 串口调试助手

配套文件：`bbcall-serial-assistant.html`（单文件，双击即用）。
命令与回包格式见 [`serial-protocol.md`](serial-protocol.md)。

---

## 1. 连接设备

**准备**
1. 焊接 / 插好串口适配器：设备 **PB10 (TX)** → 适配器 **RX**，设备 **PB11 (RX)** ← 适配器 **TX**，两端**共地**。
2. **关闭 SSCOM** 等一切占用该串口的程序 —— 串口是独占资源。
3. 确认波特率 **115200**、**8N1**。

**在助手中连接**

| 步骤 | 操作 |
|---|---|
| 1 | 顶栏 **串口** 下拉选择适配器对应的 COM 口（无列表时点「连接设备」，浏览器会弹出授权框） |
| 2 | **波特率** 保持 115200 |
| 3 | 点 **连接设备**；状态灯由「未连接」变为已连接 |
| 4 | 连接成功后助手自动发一条 `PING` 探活，并开始接收设备周期输出 |

**无硬件演示**：点 **模拟设备**。助手用内置状态机伪造固件回包（心跳、`STAT?`、`[FRAME]`、`INBOX?`、`LOG?` 等），全部交互与实机一致。再次点击即退出模拟。

**断开**：连接状态下「连接设备」按钮变为断开；点一下即释放串口。

> **`file://` 打不开串口** —— Web Serial 要求安全上下文。用 `npx serve`、VS Code Live Server 等本地服务器打开，或先用模拟设备。

## 2. 左栏 · 设备状态

| 模块 | 说明 |
|---|---|
| **RSSI / SNR / 频点** | 三张 KPI 卡，来自 `STAT?` 与 2 秒周期 `R19=` 回包 |
| **状态表** | 常看 6 项：`G`、`AGC`、`SQ`、`SQN`、`FREQ`、`DUPMS` —— 调参后可即时核对设备是否接受 |
| **更多诊断计数**（折叠） | 展开后显示 `SQN / I2CE / ID / RX / U / DUP / FIX / ISRavg / ISRmax / 上电时长` 等 |
| **S-meter** | 优先采用设备心跳 `S=` 回包里的 `bk4802_get_smeter()` 读数；设备静音时 `M=1` 会被回包反向确认 |
| **屏幕镜像** | 128×64 点阵，Canvas 像素级复刻，见 §5 |

时间戳（`statAge`）显示最后一次状态回包的距今时间；长时间不刷新说明设备未回包，检查接线或串口占用。

## 3. 中栏 · 控制台

**过滤**：`全部 / 帧 / 状态 / 记录 / 错误` 五个分组，括号内为实时计数。分组内部聚合多类原始标签：

| 分组 | 覆盖的标签 |
|---|---|
| 帧 | `FRAME`、`RAW` |
| 状态 | `STAT`、`CFG`、`RTC`、`LCD`、`FREQ`、`R19=`、`S=` |
| 记录 | `REC`（`[INBOX]` / `[LOG]`） |
| 错误 | `ERR`（`[I2C]`、`err:`、`[LOG] append failed`） |

**检索**：输入关键字即时过滤（不区分大小写），与分组叠加生效。
**跟随**：勾选后新日志自动滚到底部；取消可锁定查看历史。
**导出日志**：把环形缓冲区（上限 1200 行）导出为 `bbcall-serial-<时间戳>.log`，内容为「时间戳 + 标签 + 原文」。
**清空**：清空缓冲区与计数。

**命令输入**

| 操作 | 效果 |
|---|---|
| 输入命令后 `Enter` | 发送（自动补 `\r\n`） |
| `↑` / `↓` | 调出命令历史（最多 60 条，持久化） |
| `/` | 任意位置聚焦到命令输入框 |
| 快捷命令 | `STAT?` `PING` `TIME?` `INBOX?` `LOG?` 一键发送 |

发送的命令会以 `TX` 标签插入日志流，方便对照回包。

## 4. 右栏 · 配置

右栏为**标签页**，一次只显示一页；当前页会记住并在下次打开时恢复。所有控件在**未连接**时只改界面数值不下发，并弹出提示。

### 4.1 调参

| 控件 | 命令 | 取值范围 |
|---|---|---|
| 接收频率 | `FREQ=<kHz>` | ≥ 24000（预设 144.640 / 144.390 / 145.825） |
| 中频增益 | `GAIN=0..7` | 每级 3 dB；**写入会自动关闭 AGC** |
| 自动增益 | `AGC=0/1` | 开 / 关 |
| 静噪门限 | `SQ=0..255` | RSSI 门限 |
| 静噪噪声门限 | `SQN=0..255` | 噪声门限 |
| 音频静音 | `MUTE=0/1` | 通 / 断 |
| 去重窗口 | `DUPMS=0..60000` | 毫秒，同一帧在该窗口内只记一次 |
| 恢复默认 | — | 一键下发固件默认值 |

拖动滑块时数值实时预览，松手（`change`）才真正下发。设备回包会更新控件，界面与设备状态保持一致。

### 4.2 对时

| 控件 | 命令 |
|---|---|
| 用本机时间对时 | `TIME=<YYYY-MM-DD HH:MM:SS>` |
| 读取当前时间 | `TIME?` |
| 读取校时值 | `TRIM?` |
| 写入校时值 | `TRIM=±<ppm>` |

校时值 `TRIM` 用于补偿 RTC 走时误差；回包会带上实际生效值（`eff=…`）与分频比（`div=`）。

### 4.3 工具

| 按钮 | 命令 | 用途 |
|---|---|---|
| PING 探活 | `PING` | 确认链路，回 `[CFG] pong` |
| INBOX? 收件箱 | `INBOX?` | 导出设备收件箱（一行摘要 + 每条一行） |
| LOG? 设备日志 | `LOG?` | 整段导出 Flash 里掉电不丢的解码日志（旧 → 新） |
| LOG0 清空日志 | `LOG0` | 清空设备端日志并重记 |

> `LOG?` 会连续输出全部记录，112 行约耗时 1 秒。导出前先确认没有正在进行的调参操作。

## 5. 屏幕镜像

复刻设备 ST7567 128×64 点阵屏的真实渲染：

| 控件 | 选项 | 说明 |
|---|---|---|
| 状态 | **待机** / **有未读** / **收件箱** | 对应设备三态 UI（`docs/design.md`） |
| 主题 | **LCD** / **OLED** | 1-bit 反色配色，模拟不同面板 |

镜像由设备 `[LCD]` 相关输出与 `INBOX?` / `[FRAME]` 内容驱动；手动切换状态与主题只影响预览，不会改动设备。

## 6. 状态栏与持久化

状态栏四项：**已收行数 / 帧数 / 满箱丢弃（`DROPN`）/ RTC 时间**。

以下设置存于 `localStorage`（`bbcall.` 前缀），下次打开自动恢复：串口、标签页、跟随滚动、LCD 主题与状态、命令历史。

清空：浏览器开发者工具 → Application → Local Storage → 删除 `bbcall.*`。

## 7. 故障排查

| 现象 | 排查 |
|---|---|
| 下拉列表为空 / 点连接无反应 | 不是安全上下文（`file://`）；改用 `localhost` 或模拟设备 |
| 连接报错 / 打开失败 | 串口被 SSCOM 等占用，先关闭 |
| 连上但无任何输出 | 检查 PB10/PB11 是否接反、是否共地、波特率是否 115200 |
| 只有 `S=` 心跳没有 `R19=` | 2 秒周期正常，稍等；若持续缺失，检查 I2C（`[I2C]` 错误行） |
| 状态数字不更新 | 手动发 `STAT?`；仍无回包则设备未运行或串口被其他程序读取 |
| 日志行全都落到「状态」组 | 固件输出前缀与解析规则不一致，对照 `serial-protocol.md` 检查前缀 |
| `LOG?` 输出不全 | 记录较多时需等待；期间不要中断串口 |
