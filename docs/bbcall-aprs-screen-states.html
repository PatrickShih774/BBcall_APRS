复刻的是一台 BB 机
屏幕只要三态：等、瞥、读。

仓库里 RF → 音频 → ADC → 判频 → NRZI → HDLC → AX.25 → APRS 这条链路已经打通，ST7567 那块屏还没焊上去——这一稿补的是最后一段。设备只收不发、只有单色、只有三个按键，所以屏幕只需要回答：现在几点、谁发来了什么、这条到底写了什么。

为什么是这套界面

不是从审美出发挑的，是从芯片和按键倒推出来的。

  • 只有三个按键、没有返回键——前两态零层级，整机只有一层深入（收件箱），长按退出。
  • 20 KB SRAM——版面是四块固定矩形，反显恒在大格，界面状态只有"当前是哪一态"一个枚举，没有滚动缓冲。
  • 位敲 SPI，无 DMA——待机态只有时钟那 64×64 在变，其余区域不重绘。
  • 单色 1-bit——层级靠反显和 1 像素分隔线，不靠灰度。
  • 包随机到达——格子只换内容，位置永不动。

还没落地的

  1. 三格依赖尚未实现的硬件。电量只显示 高/中/低 三挡——86% 那种小数是 1-bit 屏给不出的假精度；挡位可走分压进 ADC，也可先用 STM32 内部 VREFINT（零外部元件，但只在电池直供、无 LDO 时等效）。接收时间要 RTC（固件现有的 [T=…ms] 是开机相对时间）；未读若要跨断电保留则要外部存储。
  2. 跨天的消息会被误读。只显示 10:01:16 不带日期，昨天的像今天的。建议当天只显示时间，非当天补"昨天"或月日。
  3. 亮屏只能由新包或按键触发，不能让时钟每秒刷新把背光一直点着。
  4. 收件箱进来容易出去难——这是唯一一层深入而设备没有返回键，退出规则必须写进固件按键表。
